Meetings NotebookLM Actions

Turn meeting audio into presentation files in your own Google Drive.

What the application does

This personal application runs in a private GitHub repository using GitHub Actions. It reads audio and configuration from the owner's designated Google Drive meeting folders, adds audio to the corresponding NotebookLM notebook, and saves generated PDF and PowerPoint presentations back to Drive.

NotebookLM's existing sources and the topic's prompt provide context. Processing state helps prevent duplicate sources and presentations. Original audio files are retained.

Who it is for

The application is intended for the owner's personal use. This website provides application and data-handling information; it does not provide a sign-in service or access to meeting files.

Google Drive access

The application requests the Google Drive scope to read existing meeting files and write generated presentations and processing state. This OAuth permission can cover all Drive files; the application code limits its operations to the configured meeting folders. Access is granted only after the owner completes Google's consent flow.
